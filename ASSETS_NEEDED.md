## How to capture

- **Size:** 1920×1080 or larger, 16:9. 2560×1440 is better. I crop and compress them for the web.
- **Format:** PNG straight from the game. Don't compress them yourself.
- **No HUD** unless the shot asks for it (H-06 and O-11 are UI shots).
- **One House shots:** PSX filter ON, except O-02, which must have it OFF.
- **Name each file after its code**, e.g. `H-01.png`. Any name is fine if you tell me which is which.
- If a shot is impossible right now, skip it. The box stays as a placeholder.
