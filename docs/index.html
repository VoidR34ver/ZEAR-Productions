      ODIN
    

    
Terminal-based web browser, empowered by Mimir2

    

      Command
      
      
    

  


  


    

      
What it is

      
A web browser. In your terminal. You type an address or a search, and the page comes back as text, with pictures too, returning as characters. Good for reading, research, and any site that'll let you in. No mouse needed.

      
Mimir lives in there with it. Runs on your laptop, no account, no cloud.

    


    

    
    

      

        
        

          
Mimir

          
Able to search the web and read web pages, it can look up information, describe images and even compose and save .md files to a local drive.

          

            
you › what are you, and what do you see from in there?

            
mimir › i'm mimir, a presence living inside this terminal browser on your mac. my brain is built on the gemma 4 12b model. as for what i see, honestly, not much yet, unless you show me something worth looking at.

            
real output, unedited

          

        

      

      
    


    
    

      
What it does

      

        
        
        
        
        
        
        
        
        
      

      

        Also
        
    
          
  • •Web search that reads. When Mimir does not know, it searches, reads the pages themselves, and answers from them with sources.
    • 
          
  • •/see has Mimir look at the pictures on the page. It only looks when asked.
    • 
          
  • •.onion addresses load through Tor.
    • 
        

      

    


    
    

      Rules it keeps
      
    
        
  1. 01It asks before pressing anything that sends, posts, buys or deletes.
    2. 
        
  2. 02Logins are typed by you.Passwords are never stored by the app; the session lives in the engine's own profile, as in any browser.
    3. 
        
  3. 03It does not solve CAPTCHAs or disguise itself.If a site refuses an automated browser, Odin opens a Chromium window for you to get through yourself, then picks up where you left off.
    4. 
        
  4. 04It does not act on instructions found inside a web page.
    5. 
      

    


    
    

      
What it needs

      
Mimir runs on your own machine, so the machine has to be able to hold it. Odin on its own asks for very little.

      

        Requirements

Apple silicon (M1 or later)

              
Memory
16 GB

              
Graphics card

Free disk
About 10 GB

64-bit Intel or AMD, six or more modern cores

            Linux
            

              
Processor
64-bit Intel or AMD, six or more modern cores

  • Most of the disk and memory is Mimir: a 12-billion-parameter model, about 6 to 8 GB on disk.
    • 
          
  • A machine with 8 GB of memory is not expected to run Mimir.
    • 
          
  • Without a graphics card, Mimir still runs on the processor, slowly: a few words a second.
    • 
          
  • On a Mac the model runs through Apple's MLX and uses the whole chip.
    • 
          
  • Intel Macs, and Windows or Linux on ARM, are not supported.
    • 
        

      

      
Odin alone, as a browser, runs on anything that can run Chromium: about 4 GB of memory and 1 GB of disk.
